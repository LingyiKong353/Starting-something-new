# Projects

Polished, standalone projects built from the ideas in the book. Each one gets its own folder and its own README following the template below.

## Project README template

```markdown
# Project name

One sentence on the problem it solves and who it is for.

## Demo
Screenshot, GIF, or a short transcript of a real run.

## How it works
A short description of the agents, tools, and data flow. A small diagram helps.

## Based on
Which book chapters and upstream files this builds on, with links.
(See ../ATTRIBUTION.md for the header comment to put in adapted files.)

## What I changed or added
What is mine versus what came from the book.

## How I checked it
Test cases, guardrails, trace screenshots, failure cases I found.

## Limitations and next steps
What does not work yet, and what I would improve.

## Run it
Exact commands, required environment variables.
```
